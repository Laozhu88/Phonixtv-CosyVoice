高级控制指令使用说明

1. 填写方式
语种和方言请使用上方选项；这里仅填写一条简短、明确的语气或节奏要求。不要同时堆叠多种互相冲突的要求。

2. 较容易生效的写法
请轻声朗读、请放慢语速、请开心地表达、请伤心地表达、请生气地表达。

3. 增强情绪或节奏
加入“非常”通常可增强模型的表达倾向：
请伤心地表达 → 请非常伤心地表达
请开心地表达 → 请非常开心地表达
请生气地表达 → 请非常生气地表达
请缓慢地朗读 → 请非常缓慢地朗读

4. 效果边界
“非常”不是精确的强度数值。新闻口吻、沉稳、亲切、停连等开放描述可能只有轻微差异，实际效果也会受参考音频和音色影响。建议先用一两句短文本试听。
