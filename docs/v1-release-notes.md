# V1.0.0 正式版发布说明

## 版本定位

`凤凰卫视中文台多语种、多方言智能配音工作台 V1.0.0`

当前版本为现阶段唯一正式基线版本，主要能力包括：
- 多语种配音
- 中文多方言配音
- 参考音频工作流
- 分段编辑工作流

## V1 主要能力

### 单人配音

- 音色库音色配音
- 参考音频配音
- 自动识别参考音频文字
- 参考音频波形剪辑
- 中文自然分段
- 分段编辑、重生成、恢复原始生成

### 多语种 / 多方言

- 外语语种自动翻译后配音
- 中文多方言配音
- 方言试听优先提示
- 粤语三段式工作流：原始中文稿、粤语播报稿、最终配音
- 粤语新闻播报分组与文字一致性机器预检
- 统一下载 48kHz、24-bit PCM、单声道播出标准 WAV

### 资产与配置

- 保存参考音色
- 用户自定义栏目模板 / 频道模板
- 历史任务恢复

## V1 设计原则

- 先稳定试用，不再继续堆叠新功能
- 以编导实际使用反馈驱动后续版本
- 界面保持简洁，减少非必要概念

## 已知边界

- 粤语机器预检只检查生成音频与播报稿的文字一致性，不能判断语调、专名发音或是否达到播出质量。
- 粤语成品在正式播出前仍须由粤语编辑或具备审听能力的人员复核。
- `V1.0.0` 固定使用已验证效果更好的 CosyVoice3 RL 权重，不向编导提供实验权重切换入口。

## 建议后续收集的反馈

- 哪些语种 / 方言最常用
- 哪些方言效果最不稳定
- 参考音频长度和剪辑习惯
- 分段编辑是否足够顺手
- 是否需要术语表、发音词典、批量生成等能力
