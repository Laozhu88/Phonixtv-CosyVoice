# V1 发布说明

## 版本定位

`凤凰卫视中文台多语种、多方言智能配音工作台 V1`

当前版本以内部试用为目标，重点验证：
- 多语种配音
- 中文多方言配音
- 参考音频工作流
- 分段编辑工作流

## V1 主要能力

### 单人配音

- 音色库音色配音
- 参考音频配音
- 自动识别参考音频文字
- 参考音频波形剪辑
- 中文自然分段
- 分段编辑、重生成、恢复原始生成

### 多语种 / 多方言

- 外语语种自动翻译后配音
- 中文多方言配音
- 方言试听优先提示

### 资产与配置

- 保存参考音色
- 用户自定义栏目模板 / 频道模板
- 历史任务恢复

## V1 设计原则

- 先稳定试用，不再继续堆叠新功能
- 以编导实际使用反馈驱动后续版本
- 界面保持简洁，减少非必要概念

## 建议后续收集的反馈

- 哪些语种 / 方言最常用
- 哪些方言效果最不稳定
- 参考音频长度和剪辑习惯
- 分段编辑是否足够顺手
- 是否需要术语表、发音词典、批量生成等能力
