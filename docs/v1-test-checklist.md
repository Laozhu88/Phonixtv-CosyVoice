# V1.0.0 正式版测试清单

## 启动

- [ ] 双击 [start_phoenix_tts.bat](H:\Codex pj\Phonixtv-CosyVoice\工程项目\start_phoenix_tts.bat) 可正常启动
- [ ] 浏览器可打开 `http://127.0.0.1:8090`

## 单人配音

- [ ] 输入中文文稿可正常生成普通话配音
- [ ] 导入 `txt` 文稿可正常回填
- [ ] 导入 `docx` 文稿可正常回填
- [ ] 清除文稿后，文本和文件名同时清空

## 多语种

- [ ] 选择英文后，中文文稿自动翻译成英文
- [ ] 选择日语后，中文文稿自动翻译成日语
- [ ] 选择韩语后，中文文稿自动翻译成韩语
- [ ] 自动翻译后的文稿可人工微调再生成

## 中文多方言

- [ ] 粤语可生成有效方言配音
- [ ] 选择粤语后可生成粤语播报稿，并可人工修改或恢复机器翻译稿
- [ ] 粤语生成后显示文字一致性机器预检结果
- [ ] 正式下载为 48kHz、24-bit PCM、单声道播出标准 WAV
- [ ] 四川话可生成有效方言配音
- [ ] 东北话可生成有效方言配音
- [ ] 上海话可生成有效方言配音

## 参考音频

- [ ] 上传参考音频后，自动识别文字
- [ ] 上传参考音频后，显示波形
- [ ] 参考音频可播放
- [ ] 点击“剪辑”后，可在波形上拖动两端游标
- [ ] 选区整体可左右拖动
- [ ] 起点、出点、保留时长、原始时长实时变化
- [ ] 点击“撤销”可恢复完整音频

## 音色库

- [ ] 可保存当前参考音色
- [ ] 选择已保存音色后，波形与文字正确回填
- [ ] 切回“请选择音色”后，波形与文字同步清空
- [ ] 删除音色后，状态正确清空

## 模板

- [ ] 可保存当前配音参数为模板
- [ ] 模板名会自动规范为以“模板”结尾
- [ ] 套用模板后，音色、语速、语种、方言和高级控制指令均正确恢复
- [ ] 手动修改模板参数后，模板状态自动退出
- [ ] 删除模板后，参数恢复默认状态

## 分段

- [ ] 文稿按回车自然分段
- [ ] 生成后可查看分段详情
- [ ] 每段可编辑文字
- [ ] 每段可单独调整语速、音色、语种和方言
- [ ] 每段可重生成
- [ ] 已重生成段可恢复原始生成
- [ ] 每段可下载本段音频

## 结果区

- [ ] 生成结果显示波形
- [ ] 波形可播放并跟随游标移动
- [ ] 可下载整条生成音频
- [ ] 有分段时可下载分段压缩包

## 历史任务

- [ ] 历史任务可折叠/展开
- [ ] 仅保留最近 10 条
- [ ] 恢复历史任务后，单人参数可正确恢复
- [ ] 恢复历史任务后，参考音频剪辑状态可正确恢复
