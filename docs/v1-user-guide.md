# V1 使用说明

## 启动

1. 双击 [start_phoenix_tts.bat](H:\Codex pj\Phonixtv-CosyVoice\工程项目\start_phoenix_tts.bat)
2. 打开浏览器访问 `http://127.0.0.1:8090`

## 单人配音

### 基本流程

1. 在“配音文稿”中输入或导入 `txt / docx` 文稿
2. 选择音色库音色，或上传参考音频
3. 如需剪辑参考音频，点击“剪辑”后直接在波形上拖动选区
4. 选择语种、中文方言和语速；如有需要，可填写高级控制指令
5. 点击“一键生成配音”

### 多语种

- 当语种选择为外语时，系统会自动把中文文稿翻译成目标语种
- 用户可直接在当前文稿框中微调译文后再生成

### 中文多方言

- 语种选择“中文”后，可选择具体中文方言
- 建议先用一两句短文本试听，再决定是否整篇生成

### 高级控制指令（实验性）

- 语种和方言请使用界面中的专用选项，不要重复写进指令
- 每次只写一条简短、明确的要求，例如“请轻声朗读”“请放慢语速”“请开心地表达”
- 新闻口吻、沉稳、亲切、停连等开放描述可能只有轻微差异
- 控制效果会受参考音频和音色影响，不保证精确复现

### 自然分段

- 默认按回车自然分段
- 文稿中每个回车自然段，会作为一个可单独编辑的配音段
- 用户可通过增加或减少回车，控制分段

### 分段编辑

- 生成后可点击“查看分段详情”
- 每段支持：
  - 编辑本段文字
  - 调整本段语速
  - 调整本段音色
  - 调整本段语种
  - 调整本段方言
  - 重生成本段
  - 恢复原始生成
  - 下载本段音频

## 参考音频

### 支持能力

- 自动识别参考音频文字
- 波形预览
- 波形剪辑
- 播放参考音频
- 保存为音色库音色

### 建议

- 推荐使用 `8~15 秒` 的清晰单人参考音频
- 如参考音频超过 `15 秒`，提交时会自动截取前 `15 秒`

## 栏目模板 / 频道模板

### 保存

1. 先选择一个已保存音色或系统预置音色
2. 设置语种、方言、语速和高级控制指令
3. 在模板名输入框中输入名称
4. 点击“保存当前配音参数为模板”

### 套用

- 从模板下拉中选择模板即可恢复参数和音色
- 如果后续手动改动了模板包含的参数，模板状态会自动退出

## 历史任务

- 右侧“历史任务记录”默认折叠
- 仅保留最近 `10` 条任务
- 可恢复到当前界面继续使用

## 结果区

- 波形图可播放与拖动定位
- 可下载整条生成音频
- 有分段时可下载分段压缩包
