# 凤凰卫视中文台智能配音工作台需求草案

## 一、项目目标

建设一套面向凤凰卫视中文台内部生产流程的智能配音工作台，基于 `CosyVoice` 开源 TTS 能力进行定制，满足新闻播报、专题旁白、栏目包装、短视频配音等业务场景。

该工作台需支持 Windows 环境一键启动，并以整合包形式交付，使普通员工在不安装开发环境、不配置 Python、不手工下载依赖的前提下直接使用。

## 二、目标用户

- 中文台栏目策划
- 编导与后期制作人员
- 新媒体短视频制作人员
- 包装与审片人员

## 三、核心业务场景

### 1. 新闻播报

- 输入新闻稿件
- 自动分句和停顿优化
- 可选填写实验性的高级控制指令
- 一键生成标准播音音频

### 2. 专题旁白

- 支持较长文本
- 支持语气、语速、停顿调整
- 支持多次试听和局部重生成

### 3. 短视频配音

- 支持短句快速生成
- 支持批量导出多个版本
- 支持适配社媒短视频节奏

## 四、必须具备的产品能力

- 本地可视化工作台
- 文本编辑与脚本分段
- 音色管理
- 配音参数设置
- 音频试听与重生成
- WAV/MP3 导出
- 项目保存与再次打开
- 常见问题日志导出

## 五、凤凰定制方向

- 凤凰卫视中文台品牌风格
- 适配新闻播报语感
- 适配栏目包装文案节奏
- 支持常见专有名词、地名、人名发音词典
- 后续可扩展凤凰内部审核流或素材流

## 六、非功能性要求

- 尽量离线运行
- 安装使用门槛极低
- 对普通办公电脑友好
- 错误提示清晰
- 打包后便于分发与升级

## 七、建议 MVP 范围

- 单机版 Windows 工作台
- 单角色中文配音
- 文本编辑、试听、导出
- 2 到 4 套精选音色
- 凤凰品牌化界面
- 一键启动脚本
