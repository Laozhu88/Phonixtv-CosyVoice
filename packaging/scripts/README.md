# Packaging Scripts

本目录预留给后续 V1 打包辅助脚本。

当前 V1 收官阶段，建议先人工整理，不急于写自动打包脚本。

如果后面需要自动化，建议脚本职责拆成三类：

## 1. 清理脚本

- 清空测试输出
- 清空无关日志
- 校验是否误带 `config/app.local.json`

## 2. 复制整理脚本

- 收集 `app/`
- 收集 `config/`
- 收集 `docs/`
- 收集 `models/`
- 收集启动脚本

## 3. 压缩打包脚本

- 输出标准 V1 Windows 压缩包
- 固定压缩包命名
- 写入版本说明

当前阶段先不写脚本，避免在 V1 收官时再增加新的维护面。
