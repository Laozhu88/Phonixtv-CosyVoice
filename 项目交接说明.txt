凤凰卫视中文台多语种、多方言AI智能配音工作台 V1
项目交接说明

一、项目定位
本项目为独立维护的 CosyVoice 配音工作台，服务凤凰卫视中文台节目生产，重点是多语种、中文多方言和参考音频复刻。当前 V1 已进入内部试用阶段，原则上不再无需求地新增功能。

二、主工程与正式发布目录
产品总目录：H:\Codex pj\Phonixtv-CosyVoice
主工程：H:\Codex pj\Phonixtv-CosyVoice\工程项目
正式发布根目录：H:\Codex pj\Phonixtv-CosyVoice\正式可发布版本
当前 Windows V1 正式发布快照：H:\Codex pj\Phonixtv-CosyVoice\正式可发布版本\Windows版\V1\凤凰卫视中文台多语种、多方言智能配音工作台_V1
临时打包目录：H:\Codex pj\Phonixtv-CosyVoice\工程项目\release_staging（仅用于生成临时产物，发布完成后应清空）
本地启动脚本：H:\Codex pj\Phonixtv-CosyVoice\工程项目\start_phoenix_tts.bat
本地访问地址：http://127.0.0.1:8090

三、V1 已完成能力
1. 单人配音：音色库音色、参考音频配音、参考音频识别文字、波形播放和两端游标剪辑。
2. 文稿处理：txt/docx 导入、按回车自然分段、单段编辑、重生成、恢复原始生成、单段下载。
3. 多语种与方言：外语文稿自动翻译；中文普通话和多方言选择；分段可独立改语言、方言、语速和音色。
4. 结果管理：合成结果波形、播放游标、折叠任务摘要、整体音频和分段压缩包下载、最近 10 条历史任务。
5. 资产管理：保存参考音色、置顶音色、用户自定义栏目/频道模板。模板包含音色、语速、语种、方言和高级控制指令；保存模板名称自动加“模板”。
6. 翻译设置：界面可选阿里云机器翻译、千问翻译、百度翻译、百度千帆大模型翻译；密钥仅保存于本机配置，不返回前端；已保存密钥显示掩码，并可按当前平台清除。

四、最近完成的修复
1. 未选择音色库音色、也未上传参考音频时，点击生成或单段重生成会直接提示“请先从音色库选择一个音色，或上传参考音频后再生成”，不再进入 CosyVoice 后报 zero_shot 错误。
2. 已将上述修复同步到 Windows 发布副本，并完成 Python 编译检查和 FastAPI 接口验证。
3. 翻译设置面板已改为深色风格，密钥字段使用掩码占位，并提供获取 Key 的帮助文字及“清除当前平台凭据”操作。
4. 已移除实际未生效且容易误导的“播报风格”选项；保留“高级控制指令（实验性）”，并修复 CosyVoice 3 指令格式及语种、方言与用户指令的合并逻辑。
5. 已移除多角色对话配音及顶部模式切换按钮；前端、生成接口、后端合成和历史字段兼容代码均不再保留，现有历史记录文件本身未删除。
6. 已修复 Rainfall 跨语种链路在多句文本中重复修改共享参考音频缓存、触发 `KeyError: 'prompt_text'` 的问题；适配层会为每句推理复制缓存输入，并已加入不加载大模型的回归测试。

六、V1 边界与注意事项
1. 不新增“发音词典/自定义读法”和“保存项目”功能，待真实编导需求明确后再评估。
2. CosyVoice 的情绪差异不稳定，当前高级控制指令只作为辅助控制，不应承诺精确情绪复现。
3. 个别实验性方言可能表现为带口音的普通话，应在界面和使用说明中保持客观提示。
4. 参考音频识别依赖本地 ASR 运行环境；若再次异常，先检查实际使用的 Python、faster-whisper/SenseVoice 依赖及模型目录，不要直接改动 TTS 主链路。
5. 云端部署此前存在环境和模型版本差异。未经完整回归验证前，不应把云端包标记为最终稳定发布版；优先采用官方 CosyVoice 底座和固定依赖版本。
6. 不在文档、代码或对话中输出任何用户的翻译平台 AccessKey、Secret 或 API Key。
7. 正式发布物统一放在产品总目录下的“正式可发布版本”目录；Windows 版与后续云服务器版分目录管理，不在“工程项目”或 Windows 版本目录中混放云端版本。

七、后续建议
先收集内部试用反馈，按“可复现问题、影响范围、建议优先级”记录。后续仅处理明确的稳定性、兼容性和易用性问题；新功能进入 V1.1/V2 评估，不直接叠加到 V1。
